# 🧠 Containerized Jupyter Data Science Environment using Docker

This project demonstrates how to run a **JupyterLab Data Science environment** inside a **Docker container**.  
It enables portable, reproducible, and isolated data science workflows — ideal for analytics, ML, and research.

---

## 🚀 Project Overview

This setup provides:
- A ready-to-use **JupyterLab** interface with preinstalled Python libraries like NumPy, Pandas, Matplotlib, scikit-learn, and TensorFlow.
- Full environment isolation using Docker containers.
- Easy push-pull workflow via Docker Hub for reusability.
- Source-code version control using GitHub.

---

## 🧩 Technologies Used

| Tool | Purpose |
|------|----------|
| **Docker** | Containerization of the Jupyter environment |
| **JupyterLab** | Interactive data-science IDE |
| **Python 3** | Programming environment inside the container |
| **Git & GitHub** | Version control and project hosting |
| **Kali Linux** | Development and demonstration platform |
